# 本地研究能力整合记录

0.3.0 从已有政策研究需求提炼公共接口，将论文专用脚本中的分析环节整理为可组合模块。新增模块使用标准库实现，输入由研究者提供，保留原始研究流程及其独立统计口径。

- 原叙事网络的主体焦点视图与正负关系需求，整理为 `network.py` 的分层指标、正负证据平衡和按方向扩展的焦点网络；通过统一图格式接入语义关系或人工编码。
- 原比较研究的 `deep_dive_content_analysis.py` 包含分组覆盖、机制组合和 bootstrap；公共模块 `comparison.py` 实现文档级实体覆盖、Wilson 区间、Fisher 检验及 FDR 校正。统计方法与原 bootstrap 流程分别保留。
- 原 `rebuild_mechanism_analysis.py` 的模板敏感性需求，整理为 `quality.py` 的重复正文、字符5元组相似度及模板候选组。原流程使用 TF-IDF 余弦，公开版使用 Jaccard，阈值按新方法确定。
- 原 TopicGPT 一致性脚本基于分词后的主题词；公开版在 `comparison.py` 按社区实体和政策文档计算 NPMI，直接复用图谱证据。
- 新增 `evaluation.py` 和可复用索引，为文本、局部、社区与混合模式提供统一的文档级相关性评测。
- 新增 `workflow.py` 串联上述环节，产出 HTML、CSV、SVG、网络格式和逐产物哈希，支持重复运行与缓存复用。

代码、标准格式与合成样例进入公开仓库；实际研究材料与验证记录保存在本地。独立运行命令和方法定义见 [研究工作流](RESEARCH.md)。
