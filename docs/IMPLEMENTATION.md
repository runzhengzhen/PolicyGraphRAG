# 实现说明

公开代码实现：JSONL/TXT 接入、GTFlow 结果适配、证据关系表导入、四类实体候选抽取、类型约束别名归并、共现图、PageRank、可选 Leiden、提取式社区摘要、稀疏/局部/社区/语义向量/混合检索、原文关联路径、HTML 报告、SVG 研究图、GraphML/GEXF 及 Neo4j 导出。

默认流程使用标准库。测试和演示使用合成数据，可选模型通过独立安装接入。

## 算法与数据语义

- 实体抽取：词典命中生成候选标注，保留原文位置；角色、工具类别与语义关系支持研究者复核。
- 证据校验：引句过滤检查连续字面证据及其位置。
- 图分析：PageRank 和社区发现计算无向加权共现投影；关系层保存显式方向、极性与立场。
- 全局检索：global 模式检索提取式社区摘要和覆盖证据。
- 关联路径：沿图边返回实体关联及相应原文证据。
- 缓存：按内容复用抽取、向量和摘要；图投影与社区发现全量重算。
- 主题演化：按显式日期统计社区覆盖，同一政策可计入多个社区。
- 扩展接口：在线模型和 Neo4j 活库接口可选启用，发布验证覆盖离线流程。
- 研究接入：AMR/VA 或其他外部编码结果通过公开的实体与关系格式导入。
- 分组比较：按独立政策统计实体覆盖率，输出 Wilson 区间、Fisher 精确检验与 BH 校正。
- 语料质量：检查证据引用、日期和重复正文，以字符5元组 Jaccard 标记模板候选。
- 显式网络：保留方向与极性，提供证据权重、密度、互惠率及焦点子图。
- 检索评测：共用索引，对四种离线模式按政策去重，计算相关性指标与延迟。
- 研究编排：`study` 汇总图谱、指标、图表、报告与运行清单，方法定义见 [研究工作流](RESEARCH.md)。

## 可复现验证

`tests/` 检查证据位置、同名类型约束、标识冲突、缓存复用、检索无证据处理、极性与方向保留、图表转义、标准图导出和离线数据库导出。`run_demo.sh` 在合成样本上执行基础流程、图表和现成关系接入。

发布检查核对源码范围、凭据形态、绝对路径、压缩包内容与 SHA-256，并在干净环境验证构建和安装。GitHub Actions 配置对推送和拉取请求执行测试与构建，具体状态见仓库 Actions 页面。
